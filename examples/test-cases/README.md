# Тестовые дела 777 и TEST-C1

В комплекте два дела, 65 оригиналов документов и сохранённые результаты.
Опубликовано по прямому указанию владельца проекта как тестовый комплект.
Аккаунты, пароли, сеансы входа и одноразовые коды настройки не включены.

Первый запуск `npm start` переносит комплект в `data`, только если там ещё нет `vestigo.sqlite` и не задана переменная `VESTIGO_DATA_DIR`.
Существующие дела никогда не заменяются. После запуска создайте свой аккаунт.
